# The .else icon

Paired leaf-shaped sheets suggest a material object and the context travelling beside it. The olive green and warm cream follow Carry's approved Folded Leaf direction. The mark remains a separate identity for this standalone experiment.

The source asset is `ElseIcon.png`, generated using the built-in image generation tool on October 11, 2026. `build.sh` derives the macOS icon sizes and `.icns` resource using Apple's image and icon tools. Carry's original reference asset is not copied into this repository.

Final generation prompt:

> Generate a brand-new flat graphic app icon for .else. Use Carry's attached icon only as a style reference. The result must have a completely solid, opaque, single flat olive green #6A7751 background filling the entire square edge to edge. Two completely flat warm cream #F6F3E7 leaf-shaped sheets form a quiet paired mark in the center: a more upright left leaf and an ascending diagonal right leaf, joined near their bottom tips but separated by a slim green negative-space seam. They evoke a file and the interpretation beside it. Keep them simple, with clean curves and no thin details, generously spaced from all edges. EXACTLY two solid colors. NO rounded tile, NO transparency, NO alpha channel, NO shadows, NO gradients, NO glow, NO shading, NO texture, NO noise, NO holes in the background, NO lighting effects, NO text, NO frame. The aesthetic is a simple two-color cut-paper silhouette, minimal and calm, just like the Carry reference. One finished square icon asset, not a mockup.
